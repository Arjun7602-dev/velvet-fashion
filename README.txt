VELVET FASHION - FRESH WEBSITE

Instagram: @velvet.fashion69
Profile: https://www.instagram.com/velvet.fashion69/

PUBLISH FREE WITH GITHUB PAGES
1. Extract this ZIP on your computer.
2. Open your GitHub repository named velvet-fashion.
3. Choose Add file > Upload files.
4. Upload index.html and README.txt from this folder.
5. Click Commit changes.
6. Open Settings > Pages.
7. Under Build and deployment, select Deploy from a branch.
8. Choose branch main and folder /(root), then Save.
9. Wait for GitHub Pages to publish. Your site URL will appear in Settings > Pages.

IMPORTANT
- This is a static website. Orders are sent to Instagram DM.
- It does not process card/UPI payments or manage inventory.
- Product photos, names and prices are sample placeholders. Replace them with your real products before launch.
- COD wording should only be used for areas where you can actually provide COD.
- The site uses online image/font services, so an internet connection is needed to display them.
